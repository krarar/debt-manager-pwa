Qisti (قسطي) - App Icon Package

This package contains PNG icons sized for:
- Android
- iPhone / iOS
- Web / PWA / favicon
- Windows desktop
- macOS desktop
- Linux desktop

Main source image was resized with high-quality Lanczos filtering.

Important:
For Android/iOS production builds, the generated PNGs are ready as source assets,
but Flutter may generate platform-specific launcher assets automatically.
The 1024x1024 image is the recommended master icon for store/build tooling.
